# 실기기 확인 목록 — 사나다 일본어 v0.1 (아이폰 · 아이패드 사파리)

개발 환경에는 사파리 엔진(WebKit)과 실제 기기가 없어서, 아래 항목은 **직접 아이폰과 아이패드에서 확인**해 주셔야 해요. 화면 시험은 Chromium에 아이폰·아이패드 화면 크기만 입혀서 했어요.

## 준비

1. `main`에 올리면 GitHub Actions가 GitHub Pages에 배포해요(처음 한 번 Settings → Pages → Source를 「GitHub Actions」로).
2. **사파리**로 `https://fullcharge13.github.io/Learning-Japanese/`를 열어요(다른 앱 안의 브라우저 말고).

## 확인 항목

| # | 확인할 것 | 어떻게 | 정상이면 |
|---|---|---|---|
| 1 | 첫 화면 | 주소를 열기 | 2초 안쪽에 「아하!」 유키와 「시작하기」 |
| 2 | 아이패드 크기 | 아이패드에서 세로·가로로 돌려 홈·레슨·보관함 | 글자와 카드가 아이폰보다 크게(1.3배), 가로 스크롤 없음 |
| 3 | 일본어 글꼴·후리가나 | 3장(1과) 새 단어 카드 | 한자 위에 작은 히라가나가 겹치지 않게 보임 |
| 4 | 🔊 발음 | 새 단어 카드의 🔊, 「무슨 뜻일까요?」 문제의 🔊 | 일본어 음성(Kyoko 등)으로 읽음. 무음 스위치가 켜져 있으면 안 들릴 수 있음 |
| 5 | 가나 문제에 🔊 없음 | 1장 「어떻게 읽을까요?」 문제 | 질문 옆에 🔊가 없고, 답을 낸 뒤 결과 창에만 있음 |
| 6 | 카드만으로 풀기 | 1-1과 3-1 레슨 끝까지 | 키보드가 한 번도 뜨지 않음 |
| 7 | 홈 화면 추가와 아이콘 | 공유 → 「홈 화면에 추가」 | 유키 얼굴 아이콘과 「사나다 일본어」 이름, 주소창 없이 열림 |
| 8 | 오프라인 | 7번 뒤 인터넷이 될 때 한 번 열고, 비행기 모드로 다시 열기 | 홈과 레슨이 열리고, 설정에 「오프라인 준비 끝」. 🔊는 기기 음성이라 오프라인에서도 동작 |
| 9 | 다이내믹 아일랜드·홈 막대 | 홈 화면 앱으로 홈·레슨·완료 화면 | 글자·버튼이 가려지지 않음 |
| 10 | 해치·리아 앱과 공존 | 같은 아이폰에서 해치와 한국어·리아와 파이썬을 쓰고 있었다면 번갈아 열기 | 세 앱의 XP·진도·이어 하기가 서로 섞이지 않음 |
| 11 | 저장 내보내기·가져오기 | 설정 → 저장 내보내기 → 저장 가져오기 | `sanada-japanese-save-날짜.json`이 받아지고, 가져온 뒤 XP·연속 기록·물건 그대로 |
| 12 | 오사카 사투리 | 일부러 몇 번 틀리기 | 가끔 「ちゃうちゃう!」「なんでやねん!」과 삐친/화난 유키 |
| 13 | 7일 저장 규칙 | (안내) 홈 화면에 추가하지 않은 사이트는 7일 방문이 없으면 저장이 지워질 수 있음 | 홈 화면 앱으로 쓰거나 11번으로 백업 |
| 14 | 다코야키 가게 열림 | 가타카나 평가를 통과한 뒤 홈 | 「유키의 다코야키 가게」 카드의 「가게로」가 눌림 |
| 15 | 하루 장사 | 가게로 → 장사 시작 → 손님 6명 → 정산 | 손님 그림·말풍선·카드가 잘리지 않고, 정산에 매출·XP·이야기 컷 |
| 16 | 장사 이어 하기 | 손님 몇 명 받다가 앱을 닫고 다시 열기 | 홈 카드가 「이어서 장사」, 같은 손님부터 이어짐 |
