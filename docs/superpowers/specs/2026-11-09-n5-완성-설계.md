# JLPT N5 완성 설계 (손질 · 문법 · 한자 · 모의고사)

> 날짜: 2026-11-09 · 상태: 사용자가 「추천 방식으로 N5 끝까지, 승인」 — 단계별 확인 없이 진행, 결정은 이 문서와 원장에 남김
> 앞 설계: `2026-11-09-jlpt-n5-설계.md`(JLPT 탭·N5 단어). 같은 틀(장 번호 100 이상 = JLPT 길)에 장을 더 붙인다.

## 1. 목적
JLPT 탭의 N5를 단어에서 끝내지 않고, 시험이 묻는 나머지(문법, 한자, 시험 형식)까지 앱 안에서 끝낼 수 있게 한다.

성공 기준
- N5 길 = 단어 101~114 → 문법 115~117 → 한자 118~119 → 모의고사 120. 순서대로 끝까지 풀 수 있다.
- N5 한자 79자(비공식 목록) 전부가 읽기·표기 문제로 나온다.
- 문법 18항목이 설명 카드와 문제로 나온다.
- 모의고사는 JLPT N5 시험의 문제 꼴(한자 읽기·표기·문맥·문법·문장 만들기·독해·청해)을 앱 문제로 묶는다.

## 2. 손질 (앞 브랜치의 미룬 것 5개)
1. 부자연스러운 예문 5개를 고친다(住む·勤める·まだ·そうして·ええ, 문장은 이전 대화의 표대로).
2. ない의 뜻 「없다」 → 「없어요」.
3. 복습을 JLPT 탭에서 시작했으면 끝난 뒤 JLPT 화면으로(레슨 화면 params `from`).
4. 날짜가 바뀔 때 다시 그리기를 JLPT 화면도.
5. 배지 화면 「끝낸 레슨」을 「회화 x/90 · JLPT y/z」로.

## 3. 장 구성 (JLPT 길에 붙임)

| 장 | 화면 | 내용 |
|---|---|---|
| 115 | N5·15장 문법 1 | です·の·あります/います·を·で/へ/に/と·과거와 부정 (1~6) |
| 116 | N5·16장 문법 2 | 형용사 활용·好き/上手·비교·て형+ください·ています·てもいい/てはいけない (7~12) |
| 117 | N5·17장 문법 3 | たい/欲しい·ましょう/ませんか·から(이유)/まで·も/や/ね/よ·もう/まだ·前に/後で/てから (13~18) |

문법 순서는 typed-japanese(MIT) 초급 장 순서를 따른다. 설명은 한국어로 새로 쓴다.

## 4. 문법 (115~117장)
- 원본: `data/jlpt-n5-grammar.json` — 항목마다 `{id: "g5-01", title, explain[], items[]}`. 항목 하나 = 레슨 하나(설명 카드 + 문제 5~6개). 장 끝에 평가(그 장 항목에서 고른 문제).
- 문제 꼴 두 가지, 화면은 지금 것 그대로:
  - **문법 빈칸**: 지금 예문 빈칸 문제(`choice` + `sentence`). 보기는 조사·활용형(예 「に·で·を·へ」, 「食べて·食べた·食べる·食べない」). 한국어 뜻 힌트를 함께 보여 준다.
  - **문장 만들기(★)**: `order` 문제의 카드를 낱말 덩어리로(예 「毎朝{まいあさ}」「パンを」「食{た}べます」). 카드에도 후리가나(화면에서 카드 글자를 `ruby()`로 그림, 가나 카드는 그대로 보임).
- 개념 id: `g5-01`…(단어가 아닌 문법 개념). 이름표 `concepts.js`에 「문법 · <제목>」으로, chapter 115~117. 복습 줄에 들어가면 그 장 파일에서 다시 낸다(지금 복습 방식 그대로).
- 예문은 N5 단어 안에서 쓰고, 한자에는 후리가나(kuroshiro 도구 + 사람 확인).

## 5. 한자 (118~119장)
- 원본: `vendor/kanji/n5.json` — [kanji-data](https://github.com/davidluzgouveia/kanji-data)(MIT, 데이터는 KANJIDIC — EDRDG CC BY-SA 4.0)에서 N5(jlpt_new=5) 79자의 음·훈 읽기·획수만. WaniKani 칸은 쓰지 않는다.
- 한국어 훈음(예 「日 = 날 일」)은 새로 쓴다: `data/jlpt-n5-kanji.csv`(`kanji, ko, chapter, unit`).
- 문제는 JLPT 단어 표(`data/jlpt-n5.csv` + 회화 단어)에서 그 한자를 쓰는 단어로 자동 생성:
  - **한자 읽기**(漢字読み): 「<단어, 후리가나 없이>」 → 읽기 4지선다(오답은 같은 장 한자 단어의 읽기).
  - **표기**(表記): 「<읽기 히라가나>」 → 한자 표기 4지선다(오답은 같은 장의 다른 한자 단어 표기).
  - 한자마다 쓰는 단어 2개(없으면 1개). 단원 하나에 한자 8~10자.
- 카드: 「日 · 날 일 · 음 にち·じつ / 훈 ひ·か」 + 그 한자 단어.
- 개념 id: `k5-<한자>`(예 `k5-日`). 이름표 「한자 · 日 날 일」.

## 6. 모의고사 (120장)
- 레슨 3개(「모의고사 1·2·3」, 모두 평가 레슨). 한 회 25문제:
  - 문자·어휘: 한자 읽기 4 · 표기 3 · 문맥(예문 빈칸) 4 · 듣고 뜻 고르기는 청해로
  - 문법: 문법 빈칸 4 · 문장 만들기 2
  - 독해: 짧은 글 1편 + 문제 2(직접 씀, `data/jlpt-n5-mock.json`)
  - 청해: 듣고 고르기 6 — 🔊 단추로 문장을 듣고(글자는 안 보임) 알맞은 뜻을 고름. 새 문제 꼴 `listen`(choice + `qSay`, 질문에 일본어 없음)
- 문제는 앞 장들의 문제에서 회마다 다른 시드로 고르고, 독해·청해 문장은 원본 파일에서.
- 결과 화면은 지금 완료 화면(「한 번에 맞힘 %」)을 그대로 쓴다. 따로 합격선 표시는 하지 않는다(공식 채점과 다름).

## 7. 화면·규칙 변경
- 레슨 화면: `order` 카드 글자를 `esc` 대신 `ruby()`.
- 내용 점검(`tests/content.py`): 문법·한자·청해·독해 문제는 단어 규칙(정답=단어 표기/뜻) 대신 각자 규칙(정답이 보기 안에 있음, 보기 4개 서로 다름, 후리가나, 문장 만들기 카드를 이으면 정답 문장).
- 완료 화면 「N5 단어 완주!」는 JLPT 길 마지막 레슨(모의고사 3)을 처음 끝냈을 때 「N5 완주!」로.
- 끝 문구: 「N5를 모두 마쳤어요! N4는 다음 업데이트에 열려요」.
- 설정 JLPT 묶음 이름 「JLPT N5」 그대로, 장 20개.
