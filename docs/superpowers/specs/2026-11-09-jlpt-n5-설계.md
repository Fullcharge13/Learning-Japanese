# JLPT 탭 · N5 단어 설계

> 날짜: 2026-11-09 · 상태: 사용자 검토 대기 · 방식 A(장 번호 구역 나누기)

## 1. 목적

지금 학습 탭(NHK 순서의 일상 회화 길, 1~26장)은 그대로 두고, 아래 탭 「학습」과 「배지」 사이에 **JLPT 전용 학습 탭**을 새로 둔다. 1단계는 **JLPT N5 단어 전체**다. 2단계 이후(N5 문법·한자·모의고사, N4~N1)는 이 틀에 붙인다.

사용자가 정한 것
- 회화 학습 메뉴는 그대로, JLPT는 따로 탭.
- JLPT 탭은 가나 2장(히라가나·가타카나 평가)을 끝내면 열린다.
- N5 단어는 회화 길과 겹치는 것까지 **전부** 넣는다.
- 기준 목록: [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks)(MIT, 별 1,000개 미만이지만 예외로 승인).
- 방식 A: JLPT 장은 번호 101번부터(N4는 나중에 201번부터).

성공 기준
- 가나 2장을 끝낸 학습자가 JLPT 탭에서 N5·1장~14장을 순서대로 끝까지 풀 수 있다.
- 정리한 N5 목록 664개가 하나도 빠짐없이 레슨에 들어 있다.
- 회화 길 화면·진도·가게는 바뀌지 않는다.

## 2. 단어

### 2-1. 기준 목록과 정리
- 원본: `open-anki-jlpt-decks/src/n5.csv`(718줄). 저장소에 `vendor/jlpt/n5.csv`와 `vendor/jlpt/LICENSE`(MIT)로 보관한다. **단어·읽기·급수만 쓰고 영어 뜻 칸은 쓰지 않는다**(출처 불분명).
- 정리 규칙(도구가 자동으로 하고 시험으로 확인):
  - 접사·조수사 줄(`～`가 붙은 41줄, `お～`, `何～`)은 단어 카드에서 뺀다. 대신 숫자 장에서 실제 말 약 25개(三時·二人·三枚·一冊·二本·一匹·一杯·一階·百円 등)로 가르친다. ～だけ·～など·～ずつ 같은 문법성 접사는 2단계(N5 문법)로.
  - 옛날 말 12개를 뺀다: テープ, テープレコーダー, ラジオカセ, レコード, マッチ, 灰皿, フィルム, 字引, 万年筆, たばこ, 背広, ストーブ.
  - 한 줄에 표기가 둘인 것(`足; 脚`)은 첫 표기, 같은 (표기, 읽기) 중복은 하나.
  - 결과: **664개**(= 「정리한 N5 목록」, 범위 시험의 기준).
- 읽기는 JMdict(지금 쓰는 `tools/jmdict_subset.py`)로 대조한다. 원본의 「(する)」 같은 메모는 떼고 대조한다.

### 2-2. 단어 표 `data/jlpt-n5.csv`
칸: `id, chapter, unit, jp, ko, pos, note`
- 회화 길(`data/words.csv`)에 이미 있는 단어(약 230개): `id`만 기존 번호(예 `c5-012`), `jp`·`ko`·`pos`는 비워 두고 생성기가 기존 표에서 가져온다 → 두 길의 표기·뜻이 어긋나지 않고, 복습·약한 단어 기록을 같이 쓴다.
- 새 단어: `id`는 `c<장>-<순번>`(예 `c101-001`), `jp`는 후리가나 표기(`昨日{きのう}`), `ko`는 직접 쓴 한국어 뜻.
- `chapter`는 101~114, `unit`은 장 안 단원(단원 하나에 6~8단어).
- 빈칸 예문: 문맥이 필요한 단어(동사·부사·의문사·지시어 등 약 150개)는 `data/examples.csv`에 지금과 같은 모양(`[[…]]` 빈칸)으로 직접 쓴 예문을 단다. 후리가나는 kuroshiro(MIT)로 달고, 번역투는 yomiyasu(MIT)의 calques 목록으로 점검한다(둘 다 개발 도구, 앱에는 안 들어감).
- 새 한국어 뜻(약 430개)은 구현 중간에 표로 사용자 검토를 받은 뒤 레슨을 만든다.

### 2-4. 레슨
- `tools/make_lessons.py`가 101~114장도 지금과 같은 방식으로 만든다: 단원 레슨(`101-1`…) + 장 평가. 레슨 이름은 「1단원」 대신 주제가 보이게 「숫자 1」처럼 단원 이름을 단다(단어 표의 단원 이름 칸 또는 장 주제 + 번호).
- 문제 유형은 지금 것 그대로: 뜻 고르기, 일본어 고르기, 가타카나 말 가나 카드 순서, 빈칸 예문. 새 유형 없음.
- 같은 뜻 보기(정답이 둘로 보이는 문제) 막기는 지금 `_twins` 규칙을 그대로 쓴다.

## 3. 화면

### 3-1. 아래 탭
학습 · **JLPT** · 배지 · 보관함 · 설정(5칸). JLPT 아이콘은 새로 그린 과녁 모양(`icon("target")`).

### 3-2. JLPT 화면 (`src/ui/jlpt.js`, 화면 이름 `jlpt`)
- 잠김(가나 2장 평가를 아직 안 끝냄, 개발자 모드 아님): 유키 「히라가나·가타카나를 끝내면 JLPT 공부가 열려요」 + 「가나 배우러 가기」(학습 탭으로).
- 열림, 위에서 아래로:
  1. 상태 줄(공통)
  2. 급수 고르기: N5(선택) · N4 · N3 · N2 · N1(「준비 중」, 누를 수 없음)
  3. 유키 인사 + 「N5 단어 664개 중 N개 배웠어요」(N = 정리한 목록의 단어 중, 끝낸 레슨(어느 길이든)에서 나온 단어 수)
  4. 「이어서 배우기 · N5·3장 숫자 2」 단추
  5. 복습 카드(홈과 같은 복습, 두 길의 단어가 함께)
  6. 학습 길: 홈 학습 길과 같은 모양으로 101~114장만
  7. 끝 문구: 「N5 단어를 모두 마쳤어요! N4는 다음 업데이트에 열려요」
- 레슨 완료 화면의 「홈으로」는 JLPT 레슨이면 JLPT 화면으로 돌아간다.

### 3-3. 진도 규칙
- 장 번호로 길을 가른다: `trackOf(chapterId)` = `chapterId >= 100 ? "jlpt" : "talk"`(이 규칙은 한 곳에만).
- 열림: JLPT 첫 레슨(101-1)은 JLPT 탭이 열리면 열린다. 그 뒤는 길 안에서 앞 레슨을 끝내야 열린다(회화 진도와 무관).
- 「이어서 배우기」(길마다): 회화는 지금 그대로(`current_lesson`), JLPT는 저장하지 않고 「JLPT 길에서 열려 있고 안 끝낸 첫 레슨」.
- 회화 홈의 학습 길·「이어서 배우기」·끝 문구·과정 완주는 회화 장만 본다.
- N5 완주: N5 마지막 평가(114장 평가)를 처음 끝내면 완료 화면 제목이 「N5 단어 완주!」. 배지는 만들지 않는다.
- XP·엔·오늘 목표·연속 기록·일일 퀘스트·배지 집계는 두 길이 함께.

### 3-4. 영향받는 곳
- 설정 「학습 내용」: 지금 목록(회화) 아래에 「JLPT N5」 묶음(14장, 장마다 끝낸 수).
- 다코야키 가게: `examIds()`(가게 열림·손님 대사 범위)는 회화 장만. JLPT 평가는 세지 않는다.
- 개발자 모드: 지금 `gateCompleted`(모든 레슨을 끝낸 것으로)가 JLPT 레슨과 JLPT 탭 잠금까지 덮는다.
- 오프라인: JLPT 장 파일도 회화 장처럼 장 파일로 나뉘어 미리 받는다(빌드가 자동).

## 4. 저장
- 새 저장 칸 없음, `saveVer` 그대로. JLPT 레슨 완료는 `completed_lessons`에 `101-1` 같은 번호로 들어간다.
- 하던 레슨 이어 하기는 같은 기록 칸(레슨 번호로 구분).

## 5. 출처 표시
- `licenses.txt`(빌드가 만드는 오픈 소스 고지)와 설정 아래 출처 줄에: 「JLPT 급수 목록: open-anki-jlpt-decks (MIT) · 원본 tanos.co.uk (Jonathan Waller, CC BY)」.
- kuroshiro·yomiyasu는 개발 도구로만 쓰여 앱 고지에는 넣지 않는다(README 「도구」에 적음).

## 6. 시험
- 단어 표(pytest): 정리한 N5 목록 664개가 모두 들어 있음 · 새 id 겹침 없음 · 기존 id가 `words.csv`에 있음 · 새 단어 후리가나·한국어 뜻 있음 · JMdict 읽기 대조 · 옛날 말 없음 · 장 101~114, 단원 6~8단어.
- 레슨 생성(pytest·content.py): 101~114장 레슨 번호 `101-1`…, 같은 뜻 보기 없음, 레슨 이름이 「n단원」이 아님.
- 규칙(node:test): `trackOf` · 길별 「이어서 배우기」와 열림 · JLPT 탭 잠금(가나 2장, 개발자 모드) · N5 완주 판정 · 가게 `examIds`가 JLPT를 세지 않음 · 「N개 배웠어요」 셈.
- 화면(flow): 가나 전 JLPT 잠김 → 가나 뒤 열림 → 101-1 풀기 → 「홈으로」가 JLPT 화면 → 회화 「이어서 배우기」 그대로 · 탭 5칸과 JLPT 화면 넘침 0(기기 5종) · 개발자 모드에서 N5 모두 열림.
- 합치기 전: 학습 시뮬레이션(가상 학습자가 N5 레슨 전부 풀기) 다시 돌림, N5 범위 다시 재기(정리한 목록 기준 100%).
