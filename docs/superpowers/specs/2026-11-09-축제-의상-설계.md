# 보관함 축제 의상 설계

> 날짜: 2026-11-09 · 상태: 사용자 검토 대기 · 방식 A(물건 칸을 그대로 의상 칸으로)

## 1. 목적

보관함의 일본 물건 34개(유키 오른쪽 위에 겹쳐 보임)를 **일본 지역 축제 의상 15벌**로 바꾼다. 의상은 유키가 직접 입은 그림으로 보인다.

사용자가 정한 것
- 사용자가 준 유키 의상 시트(`docs/img/ref/yuki-festival-sheet.jpg`, 2576×1438, 5열×3행)의 15벌만 쓴다. 옷걸이 시트는 쓰지 않는다.
- 지금처럼 **엔으로 산다**.
- 옛 물건은 모두 빼고, **산 값을 엔으로 돌려준다**.
- 입은 모습은 **지금 물건이 보이던 곳에 그대로** 나온다.

성공 기준
- 보관함에 「평소 옷」 + 의상 15벌(16칸)이 보이고, 사고·입고·벗을 수 있다.
- 옛 저장을 불러오면 옛 물건 값이 한 번만 엔으로 돌아오고, 안내가 한 번 뜬다.
- 의상을 입으면 시작 화면·홈 인사·레슨 완료·축하 창·홈 화면 추가 안내에 의상 그림이 나온다.

## 3. 그림

- `tools/cut_sheets.py`: 물건 시트 자르기를 빼고, 의상 시트 15칸을 `src/img/outfits/<id>.png`(256px 정사각형)로 자른다.
  - 칸 좌표는 이름표·제목을 지운 시트에서 배경과 다른 덩어리를 찾아 정한 값(지금 유키 시트와 같은 방법).
  - 이름표·제목·맨 위 등불은 배경색으로 덮어 지운다. 그림 곁 작은 장식(꽃잎·불꽃·칠석 장식)은 남긴다.
  - 크림색 배경에 가까운 픽셀은 투명하게(지금 `cut()`과 같은 방식, 기준색만 크림색).
  - 미리보기 `docs/img/outfits-preview.png`.
- `src/img/items/` 34장은 지운다. 이 그림을 가리키는 코드가 남지 않는다.
- 알려진 한계: 2-3·2-4·1-5 핫피의 한글은 그림의 일부라 남는다. 나중에 그 칸만 다시 그린 낱장으로 바꿀 수 있다.

## 4. 저장 (`src/save.js` migrate)

저장을 불러올 때마다(앱 시작·저장 파일 가져오기·개발자 모드 칸 모두 migrate를 지난다):
- 옛 물건 값 표 `OLD_ITEM_PRICES`(옛 34개 중 가격 있는 33개)로, `items`에 든 옛 물건 값을 더해 `bytes`에 돌려준다.
- 옛 `kadomatsu`가 있으면 `nebuta`를 준다.
- `items`에는 새 의상 id와 `none`만 남긴다. `item`이 새 의상이 아니면 `"none"`.
- 돌려준 엔이 있으면 `item_refund: <엔>`을 남긴다. 앱은 시작 뒤 한 번 안내하고 이 칸을 지운다.
  - 안내: 「보관함이 축제 의상으로 바뀌었어요. 가지고 있던 물건 값 N엔을 돌려드렸어요.」
- 한 번만: 옛 물건이 목록에서 빠지므로 두 번째 migrate는 아무것도 돌려주지 않는다.

`src/rules.js`의 30일 연속 보상은 `kadomatsu` 대신 `nebuta`.

## 5. 화면

- `yukiImg({ face, item, size })`: `item`이 의상이면 `img/outfits/<id>.png`(alt 「<의상 이름> 의상을 입은 유키 선생님」), `none`이면 지금처럼 표정 그림. 부르는 곳은 그대로라 시작·홈 인사·레슨 완료·축하 창·홈 화면 추가 안내에 자동으로 적용된다. 레슨 중 반응(`item` 없이 부름)은 늘 표정 그림.
- 보관함: 목록 칸 그림은 의상 그림, `none`은 지금처럼 표정 그림. 표시 「입는 중 / 가짐 / N엔 / 30일 보상」, 단추 「사기 / 입기 / 벗기」. 「물건」이라는 말은 「의상」으로.
- 배지 `collector`: 이름 「의상 수집가」, 설명 「축제 의상 3벌 모으기」(판정은 그대로).
- 대사 `item_bought`: 물건 → 의상 말투로.

## 6. 시험

단위(node)
- 의상 표: 16칸, id 겹침 없음, 가격 분포, nebuta 판매 안 함, 옛 id와 겹침 없음, jp 후리가나.
- migrate: 당고+기모노 → +360엔·items ["none"]·item "none"·item_refund 360 / kadomatsu → nebuta / 두 번 불러도 한 번만 / 섞인 저장은 의상 유지.
- 사기·입기: 엔 부족 거절, nebuta 구매 거절, 안 가진 의상 입기 거절.
- 30일 연속 → nebuta.
- yukiImg: 의상 → outfits 그림, none → 표정 그림.

그림(pytest)
- outfits 15장, 네 모서리 투명, 가운데 불투명. `src/img/items` 없음, 빌드에 `img/items/` 참조 없음.

화면(flow)
- 오사카 의상 사기 → 입기 → 홈 인사에 의상 그림 → 벗기 → 표정 그림.
- 옛 물건 저장으로 열기 → 안내 한 번·엔 증가 → 다시 열면 안내 없음.
- 기존 넘침·터치 시험이 보관함 16칸을 덮는다.

특히 볼 곳: 엔 두 번 돌려주기, 옛 저장 파일 가져오기, 개발자 모드 칸.
