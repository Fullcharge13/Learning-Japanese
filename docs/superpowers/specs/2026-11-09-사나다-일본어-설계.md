## 1. 의도

한국어를 쓰는 일본어 입문자가 아이폰·아이패드 브라우저에서 하루 5~10분, **카드만 눌러서**(타이핑 없음) 가나와 기초 단어를 익히는 듀오링고식 웹앱. 선생님은 사나다 유키. 무료 공개, 서버 없음. 지인용이지만 공개 저장소·공개 앱이어도 괜찮아야 한다(그래서 NHK 내용을 옮기지 않는다).

### 사나다 유키 (설정)

30세, 전국시대 사나다 가문의 후예, 오사카 출신. 도쿄대 일본어·일본문학(국어학)·동양사학 박사, 한국 드라마·K-팝으로 한국어를 독학한 뒤 한국외대 한국어교육과 박사. TOPIK 6급, JLPT N5~N1 지도. 상냥하고 평소에는 표준어(도쿄 말)를 쓰지만, **오답일 때 가끔 오사카 사투리로** 짚어 준다.

### 성공 기준

1. 히라가나·가타카나 장(앱 1·2장)과 1~12과(앱 3~14장) 단어 중 보류가 아닌 것이 모두 어느 레슨엔가 한 번 이상 나온다.
2. 모든 문제는 터치로만 풀린다(입력창 0개).
3. 앱 화면 글자는 한국어다. 일본어 단어의 한자에는 후리가나가 붙는다. 로마자는 쓰지 않는다.
4. 🔊 단추를 누르면 기기 내장 일본어 음성으로 읽어 준다. 음성 기능이 없는 기기에서는 단추가 나오지 않고, 나머지는 그대로 동작한다.
5. 바탕 앱의 진도·연속 기록·퀘스트·배지·보관함·오프라인·홈 화면 앱·장 따로 불러오기가 그대로 동작한다.
6. 아이폰과 아이패드(세로·가로)에서 넘침 없이 맞춰진다(바탕 앱과 같은 방식).
7. 같은 github.io 주소의 해치·리아 앱과 저장·오프라인 저장본이 섞이지 않는다(접두 `sanada-japanese.`).

### 범위 밖 (v0.1에서 하지 않음)

13~48과, 예문 빈칸 문제, 문법 설명 화면, 듣기 문제, 번체판·글자판 바꾸기, 요음·촉음 따로 배우는 가나 레슨(단어 속에서 익힌다), 계정·서버.

## 3. 레슨 만들기 (데이터 흐름)

```
data/words.csv ──> tools/make_lessons.py ──> data/lessons/chN.js, data/concepts.js ──> build.py ──> dist/
```

### 단어 표 `data/words.csv`

| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 고유 번호 `c<장>-<번호>` | `c3-004` |
| `chapter` | 앱 장 번호(§3-1) | `3` |
| `unit` | 장 안 묶음(레슨 나누기 단위) | `1` |
| `jp` | 일본어. 한자 뒤 `{읽기}`로 후리가나 | `学生{がくせい}`, `行{い}きます`, `すみません` |
| `ko` | 한국어 뜻(짧게, 보기 카드에 들어갈 길이) | `학생` |
| `pos` | 품사: `noun` `verb` `adj` `expr` `kana` 등(오답 보기 고르기용) | `noun` |
| `status` | `ok` · `hold`(레슨에서 뺌) | `ok` |
| `note` | 설명(해설에 덧붙임, 비어도 됨) | |

- **읽기(가나)** = `jp`에서 `한자{읽기}`를 읽기로 바꾼 것. **표기** = `{...}`를 지운 것.
- 단어·뜻은 이 앱을 위해 Claude가 새로 쓴다. 읽기는 공개 사전 JMdict(EDRDG, CC BY-SA 4.0)로 기계 확인한다(§8). 뜻은 별도 검토 에이전트가 교차 검토한다. 원어민 검수 전이라는 점을 README 「알려진 한계」에 적는다.
- 단어 표와 생성물의 라이선스: CC BY-SA 4.0(JMdict 대조 결과를 담으므로). 코드는 MIT.

### 3-1. 장 구성

| 앱 장 | 제목 | 내용 |
|---|---|---|
| 1 | 히라가나 | 기본 46자 + 탁음·반탁음 23자(ぢ·づ 제외) |
| 2 | 가타카나 | 기본 46자 + 탁음·반탁음 23자(ヂ·ヅ 제외) |
| 3~14 | 1과~12과 | NHK 1~12과 **주제**를 따른 새 단어 10~15개씩(표현 포함) |

NHK 1~12과 주제(우리 말로 새로 붙인 제목): 1 장소 묻기 · 2 자기소개 · 3 출신 말하기 · 4 하는 일·공부 · 5 지난 일 말하기 · 6 전철 타기 · 7 부탁하기 · 8 친구 소개 · 9 물건 이름 묻기 · 10 값 묻기 · 11 있는지 묻기 · 12 느낌 말하기.

- 가나 장의 `jp`는 글자 하나, `ko`는 한글 소리(「か」=「카」, 「ん」=「응」, 「を」=「오 (조사)」). 같은 소리를 비교할 때는 괄호 앞부분만 본다(§4-1).
- **레슨** = 단원(`unit`) 하나를 표 순서대로 **8개씩** 끊은 묶음(남는 4개 이하는 앞 레슨에 붙임). 장 끝에 장 평가 1개(`isExam`).
- 레슨 모양은 바탕 앱 그대로: `cards`(새 단어 카드, 카드마다 4개), `items`(터치 문제 max(6, 단어 수), 장 평가 8개) + `check` 1개. `id`는 「3-2」처럼 장-순번, `concept`는 단어 `id`.
- 같은 입력이면 같은 출력(시드 = 단어 id).

## 4. 문제와 화면

### 4-1. 문제 종류 (기존 choice·order 화면만 씀)

| 종류 | type | 질문 | 보기 | 대상 |
|---|---|---|---|---|
| 일→한 | choice | 「学生{がくせい}」은 무슨 뜻일까요? | 한국어 뜻 4개 | 단어 장 |
| 한→일 | choice | 「학생」은 일본어로? | 일본어 4개(후리가나) | 단어 장 |
| 가나 맞추기 | order | 가나 카드를 순서대로: 「학생」 | 읽기를 가나 단위로 자른 카드(요음 「きょ」, 작은 「ゃゅょ」는 앞 글자에 붙임). 2~6장 | 단어 장, 읽기가 2~6단위 |
| 글자→소리 | choice | 「か」는 어떻게 읽을까요? | 한글 소리 4개 | 가나 장 |
| 소리→글자 | choice | 「카」는 어느 글자일까요? | 가나 4개 | 가나 장 |

- 오답 보기: 같은 장·같은 품사 → 모자라면 같은 장 아무 품사. 정답과 뜻이 같거나(괄호 앞부분 비교) 표기·읽기가 같은 단어는 뺀다(정답이 둘로 보이지 않게). 가나 장에서는 히라가나·가타카나가 같은 소리이므로 서로 오답이 되지 않는다.
- 해설: 「学生{がくせい} = 학생」 + `note`.
- `check`: 그 레슨에서 아직 안 낸 일→한(또는 소리) 문제 하나.

### 4-2. 후리가나

`src/ruby.js`의 `ruby(text)`: 글자를 이스케이프한 뒤 `한자{읽기}`를 `<ruby>한자<rt>읽기</rt></ruby>`로 바꾼다. `{`가 없는 글자는 이스케이프만. 일본어가 나올 수 있는 곳(문제, 보기, 해설, 정답, 단어 카드, 유키 말풍선)은 `esc` 대신 이것을 쓴다. 가나 맞추기 카드는 가나라 그대로. 읽기 함수 `kana(text)`와 표기 함수 `plain(text)`도 같은 파일에.

### 4-3. 🔊 발음

`src/speak.js`의 `canSpeak()`·`speak(text)`: `window.speechSynthesis`와 `SpeechSynthesisUtterance`가 있으면 `lang = "ja-JP"`, 읽기(`kana(jp)`)를 읽는다. 앞 소리는 멈추고 읽는다. 없으면 `canSpeak()`가 false → 단추를 그리지 않는다. 설정의 「소리」 끔은 효과음만 끄고 발음 단추는 남긴다(사용자가 직접 누르는 것이므로). 단추 자리: 새 단어 카드의 단어마다, 일→한·글자→소리 문제의 질문 옆, 결과 패널(정답 일본어). 단추는 44px 이상, `aria-label="발음 듣기"`.

## 6. 일본 물건 (보관함)

- 두 시트에서 35개를 자른다. **하치마키는 넣지 않는다**(욱일 무늬; 한국 학습자 대상). 「타비 신발」은 「지카타비」로 이름 붙인다. 한 칸에 여러 물건이 섞인 시트 2의 3행(오마모리·말차·코케시·고토와 샤미센·토리이·종이학)은 깨끗이 자를 수 있는 것만 쓰고, 못 자르는 것은 빼서 표에 남기지 않는다.
- `data/items.js`: `{ id, ko, jp, price }`. 화면 이름은 「기모노 · 着物{きもの}」. 값은 60~300엔 5단계, 「가도마츠」는 판매 안 함(30일 연속 보상, 바탕 앱 「북」 자리).
- 재화 이름: 「엔」(저장 칸은 `bytes` 그대로).
- 배지 「물건 수집가」 조건(3개)은 그대로.

## 8. 오류 처리

바탕 앱의 처리를 그대로 둔다(저장 실패 알림, 저장소 막힘, 장 파일 못 받음, 새 판). 새로 생기는 경우:

- 음성 없음·읽기 실패: 단추를 그리지 않거나, `speak`가 예외를 삼키고 아무것도 하지 않는다(학습은 계속).
- 단어 표 오류(`{}` 짝 안 맞음, 빈 칸, 알 수 없는 status, id 중복): `make_lessons.py`가 줄 번호와 함께 `ValueError`로 멈춘다.

| `python3 tests/build_test.py` | 한 장 HTML, 크기, 오프라인, 장 파일, 출처 표시, 저장본 접두 |
| `python3 tests/flow.py` | 아이폰 3종·아이패드 화면 순회: 넘침·터치 크기·입력창 0개·후리가나 보임·해치 앱 저장과 공존 |

JMdict 대조는 `tools/jmdict_subset.py`가 사전 파일에서 `words.csv` 단어만 뽑아 `vendor/jmdict/subset.json`(출처·라이선스 파일 함께)에 두고, 시험은 이 부분집합만 본다. 사전 파일을 이 환경에서 받지 못하면 대조 시험은 건너뛰고(이유 표시), 그 사실을 README 한계에 적는다.
