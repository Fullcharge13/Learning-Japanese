# JLPT N5 채우기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** N5 길에 문법 4·5(120·121장), 독해(122장), 청해(123장)를 더하고 모의고사를 124장으로 옮겨, N5 시험 영역을 모두 연습할 수 있게 한다.

**Architecture:** 지금 생성기(`tools/make_lessons.py`)의 「직접 쓴 문제」 장 방식을 그대로 넓힌다(문법은 같은 JSON에 항목 추가, 독해·청해는 새 원본 JSON). 소리는 `speak()`가 줄바꿈 대화를 줄마다 높낮이를 달리해 읽게 하고, 저장은 `SAVE_VER` 3에서 `120-n`을 `124-n`으로 한 번 옮긴다.

**Tech Stack:** 바닐라 JS, node:test, Python(pytest, Playwright), kuroshiro(개발 도구).

**Spec:** `docs/superpowers/specs/2026-11-10-n5-채우기-설계.md`

## Global Constraints
- 장 id: 문법 4 = 120, 문법 5 = 121, 독해 = 122, 청해 = 123, 모의고사 = 124. 화면 「N5 · 20장 문법 4」…「N5 · 24장 모의고사」.
- 개념 id: 문법 `g5-19`~`g5-30`, 독해 `r5-01`~`r5-12`, 청해 `l5-01`~`l5-20`. 이름표 「문법 · …」, 「독해 · <제목>」, 「청해 · n」.
- 대화 표기: `say`에 `\n`으로 줄, 줄 앞 `男：`/`女：`(전각 콜론). 남 pitch 0.8, 여 pitch 1.25, 표시는 읽지 않음.
- `SAVE_VER` 2 → 3. 옛 판(< 3)만 `120-n` → `124-n`.
- 모든 일본어 한자에 후리가나, N5 단어 안에서. 청해 1·2·4 질문에 일본어 없음. 청해 3·4 보기 3개, 나머지 4개.
- 모의고사 회당 25문제 그대로.

## Review Focus
1. 모의고사를 이미 끝낸 옛 저장 → 24장 끝남, 20장 문법 4는 안 끝남(잘못 열림·완료 표시 없음) → Task 1 `migrate` 단위 시험 + Task 6 flow.
2. 옛 판에서 모의고사를 풀던 중(하던 레슨 `120-2`) → 이어 하기가 문법 4가 아니라 모의고사 2로 → Task 1 resume 옮기기 단위 시험.
3. 대화가 아닌 한 줄 문장(지금 모든 🔊) → 지금과 똑같이 읽힘(pitch 기본, cancel 한 번) → Task 2 단위 시험.
4. 일본어 목소리 없는 기기에서 대화 문제 → 「글자로 보기」에 남·여 줄이 다 보임 → Task 2 단위 시험.
5. 복습 줄에 `r5-`·`l5-` 개념 → 그 장 파일에서 문제를 다시 냄(이름표 있음) → Task 4·5 concepts 시험.
