# JLPT 탭 · N5 단어 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 아래 탭에 JLPT 탭을 새로 두고, 가나 2장 뒤 열리는 N5 단어 14장(101~114장, 664단어)을 회화 길과 따로 진행하게 한다.

**Architecture:** 장 번호 100 이상 = JLPT 길(`src/track.js`의 `trackOf` 한 곳). 단어는 `data/jlpt-n5.csv`(겹치는 단어는 기존 id만)에서 `tools/make_lessons.py`가 기존 방식대로 `data/lessons/ch101.js…`를 만든다. 앱은 `ctx.chapters/lessons`를 회화 길만 돌려주게 좁히고, JLPT 화면(`src/ui/jlpt.js`)이 JLPT 길을 그린다.

**Tech Stack:** 바닐라 JS ES 모듈, node:test, Python(pytest, Playwright), esbuild(build.py), kuroshiro(개발 도구, npm devDependency).

**Spec:** `docs/superpowers/specs/2026-11-09-jlpt-n5-설계.md`

## Global Constraints

- JLPT 장 번호 101~114, 화면 표기 「N5 · n장」(n = 장 번호 − 100). `trackOf(id) = id >= 100 ? "jlpt" : "talk"`.
- 정리한 N5 목록 = 664개(원본 718줄 − 접사·조수사 줄 − 옛날 말 12개 − 중복). 옛날 말: テープ, テープレコーダー, ラジオカセ, レコード, マッチ, 灰皿, フィルム, 字引, 万年筆, たばこ, 背広, ストーブ.
- 원본 목록은 단어·읽기·급수만 쓰고 영어 뜻 칸은 쓰지 않는다.
- 단원 하나에 6~8단어. 문제 유형은 지금 것만.
- JLPT 탭은 가나 2장(1·2장 평가) 뒤 열림, 개발자 모드면 늘 열림.
- 회화 홈·「이어서 배우기」(`current_lesson`)·과정 완주·가게(`examIds`)는 회화 장(1~26)만.
- 새 저장 칸 없음, `saveVer` 그대로.
- 출처 문구: 「JLPT 급수 목록: open-anki-jlpt-decks (MIT) · 원본 tanos.co.uk (Jonathan Waller, CC BY)」.
- 문구: 잠김 「히라가나·가타카나를 끝내면 JLPT 공부가 열려요」 / 진행 「N5 단어 664개 중 N개 배웠어요」 / 끝 「N5 단어를 모두 마쳤어요! N4는 다음 업데이트에 열려요」 / 완주 제목 「N5 단어 완주!」.

## Review Focus

1. JLPT 레슨을 끝내도 회화 「이어서 배우기」(`current_lesson`)가 바뀌지 않는다 → Task 5 `finish keeps talk current`.
2. 복습 줄에 JLPT에서만 배운 단어가 있으면 복습이 그 장(101~) 파일을 불러온다 → Task 5 `chaptersForConcepts finds jlpt chapter`.
3. 가게 손님 범위(`doneChapter`)가 JLPT 평가를 세지 않아 26을 넘지 않는다 → Task 5 `examIds talk only`.
4. 아이폰 가장 작은 화면(iPhone 17e)에서 탭 5칸이 넘치지 않고 44px 터치 → Task 6 flow 넘침·터치 시험에 `jlpt` 화면 추가.
5. 겹치는 단어가 두 장에 나와도 단어 이름표(`concepts.js`)에 한 번만, 원래 장 번호로 → Task 4 `concepts unique`.
