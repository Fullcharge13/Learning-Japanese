# JLPT N5 완성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** JLPT N5 길에 손질 5개, 문법(115~117장), 한자(118~119장), 모의고사(120장)를 더해 N5를 앱 안에서 끝낼 수 있게 한다.

**Architecture:** 단어 장과 같은 생성기(`tools/make_lessons.py`)에 「직접 쓴 문제」 장(문법·모의고사 원본 JSON)과 「한자 자동 생성」 장을 더한다. 화면은 지금 문제 꼴(choice·sentence·order·qSay)을 그대로 쓰고, 문장 만들기 카드에 후리가나만 더한다. 길 규칙(100 이상 = JLPT)과 진도 규칙은 그대로.

**Tech Stack:** 바닐라 JS, node:test, Python(pytest, Playwright), kuroshiro(개발 도구).

**Spec:** `docs/superpowers/specs/2026-11-09-n5-완성-설계.md`

## Global Constraints
- 장 번호: 문법 115·116·117, 한자 118·119, 모의고사 120. 화면 「N5 · 15장 문법 1」…「N5 · 20장 모의고사」.
- 문법 개념 id `g5-01`~`g5-18`, 한자 개념 id `k5-<한자>`. 이름표 「문법 · …」·「한자 · 日 날 일」.
- 문제 꼴은 지금 것만(choice/check/order) + `listen` 표시(choice에 `listen: true`, `qSay: true`, 질문에 일본어 없음).
- 모든 일본어 한자에 후리가나. 단, 한자 읽기 문제의 질문 단어와 표기 문제의 보기는 일부러 후리가나 없음.
- 완주 제목 「N5 완주!」(JLPT 길 마지막 레슨 = 모의고사 3), 끝 문구 「N5를 모두 마쳤어요! N4는 다음 업데이트에 열려요」.
- 출처: 「한자 읽기: KANJIDIC(EDRDG, CC BY-SA 4.0) via kanji-data(MIT)」.

## Review Focus
1. 기기가 음성을 못 낼 때(듣기 문제) → 🔊 대신 문장 글자를 보여 줘 풀 수는 있게 → Task 5 `listen fallback` 단위 시험.
2. 문장 만들기 카드에 같은 글자 카드가 둘(예 「を」 두 번) → 정답 판정은 글자 순서로(지금 `lines.join`) → Task 2 content 규칙 + Task 3 데이터 시험(카드 이어 붙이면 정답 문장).
3. 한자 읽기 오답에 정답과 읽기가 같은 단어(같은 소리) → 두 정답처럼 보임 → Task 4 `distinct readings` 시험.
4. 복습 줄에 문법·한자 개념 → 그 장 파일에서 문제를 다시 낸다 → Task 3·4 생성물에 concept가 이름표에 있음 시험.
5. 모의고사 문제 수가 너무 많아 한 레슨이 길어짐 → 회당 25문제 고정 시험(Task 5).
